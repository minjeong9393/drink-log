# SCMJ 주록

와인·위스키·맥주를 사진과 별점으로 남기는 1인(부부 공유)용 주록 웹앱(PWA)입니다.
광고·추적·외부 SDK 없이 화면 하나(HTML)로 동작하고, 사진과 기록은 기기 브라우저(IndexedDB)에만
저장됩니다. 남편과 연동하면 방 코드를 아는 기기끼리 실시간으로 같은 주록을 봅니다.

- 앱 이름: **SCMJ 주록**
- 색: 와인 `#c2335c` · 별점 금 `#efa51c` · 배경 `#faf7f9`
- 저장: IndexedDB `drink_log_db` (records · photos) + 목록 캐시 `localStorage['drink_log_meta_v1']`
- 남편 연동: Firebase Realtime Database `rooms/{방코드}/drinks/{기록id}` (REST + SSE, 외부 SDK 없음)

## 화면

| 탭 | 내용 |
| --- | --- |
| **내역** | 위에 총 기록·평균 별점·제일 많이 마신 종류·또 마실래요 요약, 월별로 묶인 기록 카드(사진 썸네일·별점·카테고리·메모) |
| **사진** | 사진이 있는 기록만 3열 사진첩으로 모아 보기 |
| **통계** | 별점 분포, 카테고리별 기록·평균 별점, 재구매 의사, 가격 합계, 별점 높은 술 |

- 위쪽 검색창에서 이름·메모·구매처 검색, 카테고리 칩(8종, 개수 표시), `최신순`·`별점순`·`★4.0+`.
- 오른쪽 아래 `+ 기록` → 술 이름(필수)·종류·별점(0.5점 단위)·마신 날·사진·메모·구매처·가격·또 마실래요.
- 카드를 누르면 사진과 메모를 크게 보는 상세 시트가 열리고 거기서 수정·삭제할 수 있습니다.

## 사진

- `<input type="file" accept="image/*">` — 안드로이드 크롬에서 카메라·갤러리 모두 열립니다.
- 붙이면 바로 미리보기가 뜨고, 캔버스로 긴 변 800px·JPEG 0.72로 줄여 저장합니다(보통 40~80KB).
- 250KB를 넘으면 640·0.55, 520·0.5로 한 단계씩 더 줄입니다. Firebase 로 보낼 때도 이 크기 그대로입니다.

## 남편 연동 (부부 공유)

`⋮ → 남편 연동` 또는 상단 `☁️ 혼자` 칩:

1. `새 방 만들기` → `wine-xxxxxx` 코드가 만들어지고 이 기기 기록이 올라갑니다.
2. `남편 초대 링크 복사` → 카톡으로 보내면 남편은 링크(`#room=...`)만 누르면 연결됩니다.
3. 다른 기기에서는 `방 코드로 참여`에 코드를 넣어도 됩니다.

- 기록 한 병을 저장하면 `/rooms/{방}/drinks/{id}` 한 군데만 PUT 합니다(사진 포함, 다른 병은 안 건드림).
- 삭제는 그 경로 DELETE + `/removed/{id}` 에 삭제 표시. 다른 기기의 옛 사본이 되살리지 않습니다.
- `EventSource`로 방 전체를 구독해 남편 폰의 추가·수정·삭제가 바로 반영됩니다.
- 연동을 해제해도 기록은 이 기기에 남습니다.
